# RPL 5.0 - Rabindranath Tagore Premier League

The Rabindranath Tagore Premier League (RPL) is the most anticipated annual sports extravaganza at IIEST, Shibpur, proudly organized by Richardson Hall. 

## Features

- **Events:** Cricket, Volleyball, Table Tennis, Badminton.
- **Participation:** Inter-departmental and Inter-hostel formats.
- **Organization:** Managed by Richardson Hall.

## Local Development

To run the project locally:

```sh
npm install
npm run dev
```

Visit `http://localhost:8080/` in your browser.
